Photo Library / Sources

Sources & authority

Source discovery is separate from permission to reproduce images. Link-only and unreviewed collections are not photo counts.

Controlling documentation comes first

  1. Bob Barrows / designer plans, drawings, specifications and engineering documentation
  2. Current Bearhawk factory manuals, service information and hardware callouts
  3. Applicable legacy Bearhawk / AviPro manuals
  4. Eric Newton Bearhawk Builder Manuals
  5. Companion builder logs
  6. Four-Place / Patrol / Five builder logs
  7. Bearhawk Forums technical discussions
  8. FAA AC 43.13 and accepted aircraft construction practice

Designer requirements control where explicit. Photographs never establish dimensions, thickness, bolt size or grip, nut type, edge distance or structural and flight-control hardware specifications.

FAA AC 43.13 is an applicable-practice reference; it does not override manufacturer design data.

How conclusions are classified
SPECIFIED
Explicitly required by controlling documentation.
STANDARD PRACTICE
Applicable accepted aircraft construction practice.
COMMON BUILDER PRACTICE
Observed across multiple builds; not a design requirement.
INDIVIDUAL BUILDER SOLUTION
Observed on one aircraft.
MODIFICATION
A documented deviation from standard configuration.
INFERENCE
Supported interpretation, not explicitly documented.
UNKNOWN
Insufficient evidence; no technical requirement established.
